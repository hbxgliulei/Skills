# Relationship Types Reference

关系类型采用**开放式分类**，不预设固定列表。以下为常见类型参考，文本中出现新类型时动态增加。

## 个人关系 (Personal)

| 类型 | 说明 | 识别线索 |
|------|------|----------|
| 家人 | 血亲/姻亲 | 父亲、母亲、兄弟、姐妹、儿子、女儿、丈夫、妻子 |
| 朋友 | 友谊关系 | 朋友、挚友、好友 |
| 同事 | 同一组织共事 | 同事、共事 |
| 师生 | 教学关系 | 老师、学生、导师、徒弟 |
| 伴侣 | 情感关系 | 男友、女友、恋人、伴侣 |
| 上下级 | 直接汇报关系 | 上级、下属、汇报给、负责 |

## 工作关系 (Professional)

| 类型 | 说明 | 识别线索 |
|------|------|----------|
| 合作 | 协作完成目标 | 合作、协作、联合 |
| 管理 | 管理与被管理 | 管理、管辖、分管 |
| 汇报 | 汇报关系 | 汇报、报告给 |
| 项目关系 | 共同参与项目 | 项目组、共同负责 |
| 客户 | 商业客户关系 | 客户、甲方 |
| 供应商 | 供应链关系 | 供应商、乙方 |
| 竞争 | 竞争对手 | 竞争、对手、 rivalry |

## 叙事关系 (Narrative)

| 类型 | 说明 | 识别线索 |
|------|------|----------|
| 主角与配角 | 叙事角色定位 | 主角、配角、旁白 |
| 对立 | 冲突对立 | 对立、反对、敌对 |
| 冲突 | 具体冲突事件 | 争吵、冲突、矛盾 |
| 支持 | 支持帮助 | 支持、帮助、援助 |
| 帮助 | 单向帮助 | 帮助、协助 |
| 影响 | 影响与被影响 | 影响、启发、引导 |

## 事件关系 (Event-based)

| 类型 | 说明 | 识别线索 |
|------|------|----------|
| 共同参与 | 共同参与某事件 | 共同参加、一起参与 |
| 共同经历 | 共同经历某事 | 共同经历、一起经历 |
| 共同组织 | 共同组织活动 | 共同组织、联合举办 |
| 共同决策 | 共同做出决策 | 共同决定、联合决策 |

## 动态扩展规则

1. 文本中出现上述列表未覆盖的关系类型时，自动新增
2. 新增类型需有至少 2 处文本证据支持
3. 新增类型在报告中标注 `[新识别]`
4. 所有类型记录在 `relationships.json` 的 `relationship_types` 字段
