# guowang-writing — 国网公文写作

WorkBuddy 技能包，按国家电网体系公文风格撰写三类材料：调研报告、会议材料、情况汇报材料。

## 功能

- **文种路由**：识别调研报告 / 会议材料（年度工作报告、领导讲话、专题报告、表态发言、总结讲话）/ 情况汇报材料三类，按对应骨架成稿
- **要素采集**：按文种核对单位、时间、署名、数据等要素，缺失项按语境合理推定并标注
- **语言规范**：内置词库、句式库、数字单位规范、对仗标题法、慎用词表
- **风格自检**：`scripts/style_check.py` 检查半角标点、直引号、单位不规范、条目不成组、段落过长、结尾收束等 7 类问题

## 技能结构

```
guowang-writing/
├── SKILL.md
├── README.md
├── references/
│   ├── 01-research-report.md      # 调研报告：七段式骨架、导语三定式、问题-措施对应、附表体系
│   ├── 02-meeting-materials.md    # 会议材料：五类子文种定式、对仗标题法、开篇结尾定式
│   ├── 03-report-briefing.md      # 情况汇报：四段式骨架、条目三段式、请求支持句式
│   └── 04-language-norms.md       # 通用语言规范：词库、句式、数字标点、自检清单
└── scripts/
    └── style_check.py             # 风格自检脚本
```

## 安装

将整个文件夹放入 WorkBuddy 技能目录：

```
~/.workbuddy/skills/guowang-writing/
```

无第三方依赖（自检脚本仅使用 Python 标准库）。

## 使用

触发词：按国网风格写、写调研报告、写会议材料、工作报告、领导讲话、表态发言、写情况汇报材料

示例：

```
按国网风格写一篇关于××工作开展情况的汇报
写篇关于××业务的调研报告，附调研表
```

成稿后自检：

```bash
python scripts/style_check.py <稿件.md>
```

需要正式 Word 件时，本技能会转交 `workbuddy-docx`；如需公文版式排版，可配合 `gongwen-paiban` 使用。

## 三类文种速查

| 维度 | 调研报告 | 会议材料 | 情况汇报 |
|------|---------|---------|---------|
| 篇幅 | 3—10 页 | 5—30 页 | 1—4 页 |
| 导语 | 缘起+方式+目的 | "主要任务是"段 | 依据+动作+"现将……" |
| 政治表述 | 少 | 必现 | 少 |
| 附表 | 常有 | 少有 | 无 |
| 结尾 | 建议清单 | 号召表态 | 总括/请求 |

共性风格：依据开篇、数据密集、对仗标题、"一是/二是"成组（≥3条）、结尾表态收束。

## 写作铁律（摘要）

1. 数据具体：金额到万元、比例两位小数、时间到日、电量到万千瓦时
2. 条目成组：条首必须为概括短语，再接具体内容
3. 会议材料标题必须对仗；情况汇报以"现将有关情况汇报如下"收尾导语
4. 问题表述讲分寸，归因指向客观条件；向上请求用"建议/恳请"
5. 单位统一：万千瓦时、kW、万元、%；不写"度"
