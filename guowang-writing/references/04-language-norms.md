# 通用语言规范与自检清单

本文件适用于三类文种。成稿前通读一遍，成稿后对照第六节自查。

## 一、词库

### 高频动词
推进、深化、统筹、协同、聚焦、锚定、聚力、落实、贯彻、梳理、摸排、压实、盘活、挖掘、孵化、前置、优化、迭代、赋能、攻坚、破题、闭环、穿透、夯实、筑牢、彰显、锻造、搭建、锁定、抢抓、深挖、拓展、培育、巩固、做实、做优

### 高频名词
质效、底数、清单、台账、专班、柔性团队、机制、界面、抓手、载体、动能、生态、标杆、示范、窗口期、基本盘、增长盘、发展盘、闭环管控、穿透式管理

### 高频修饰语
稳步、有序、有效、精准、稳妥、审慎、前瞻、系统性、实质性、高质量、持续

### 数字化概括（保留引号）
"三个方面的意见""四大核心问题""五大举措""两集中""三零办电""三个一""双轮驱动""1+2+3X"架构

## 二、句式库

| 用途 | 句式 |
|---|---|
| 总起 | "这次会议的主要任务是：……"；"下一步，重点抓好×个方面工作。" |
| 排比定义 | "是……重要路径，是……关键抓手，是……重要手段" |
| 对仗提法 | "一手抓××拓增量、一手抓××提效优存量"；"减投入、强管理、增效益"；"降碳、算碳、管碳、易碳"；"强能力、整资源、创模式、树品牌" |
| 让步转折 | "尽管……，但……"；"虽……，但……" |
| 递进 | "不仅稳住了……，更推动了……" |
| 表态 | "请总部放心，××一定……"；"奋力谱写××新篇章" |
| 请求 | "恳请省综……"；"建议市公司层面……"；"请予支持/指导" |
| 结论前置 | "结合调研情况看，……宜……"；"总体来看，……" |

## 三、数字与单位规范

- 金额：万元（保留两位小数或整数）；亿元（保留两位）
- 电量：千瓦时 / 万千瓦时 / 亿千瓦时——**不写"度"**
- 功率：千瓦（kW）/ 万千瓦 / 兆瓦——全文不混用
- 比例：保留一至两位小数（"98.87%""100%"）
- 时间：成文日期"2026年9月"；事件"9月17日""截至7月底"；区间用一字线"1—8月""2024—2027年"
- 数量+单位同现："累计签约电量136.05亿千瓦时，创收4125.64万元"

## 四、标点与层级

- 层级递进：`一、` → `（一）` → `1.` → `（1）` → `①`
- 段内并列用"一是……二是……三是……"，条目间用分号、末条用句号
- 中文引号"……"、'……'；提法、品牌、术语加引号（"双碳""十五五""全电化"）
- 书名号用于制度文件：《××管理办法》《××实施方案（2024—2027年）》；会议名称不加书名号
- 破折号用于副标题："——在××会议上的报告"

## 五、慎用与禁用

| 类别 | 避免 | 改为 |
|---|---|---|
| 口语 | 搞、弄、差不多、挺好的 | 推进、开展、基本、成效明显 |
| 绝对化 | 极大、最好、彻底解决、完全 | 明显、有效、稳步、基本 |
| 主观 | 我觉得、我们认为（正式件） | 调研中发现、结合实际看、经研判 |
| 不确定 | 可能、大概、或许 | 预计、宜、需进一步研究 |
| 情绪 | 感叹号堆叠、网络用语、表情符号 | 中文书面语 |
| 违规 | 直接写人名不写职务（首次出现） | 姓名+职务 |

## 六、自检清单（成稿后逐项核对）

1. 导语是否交代依据与目的？结尾是否有收束句（表态/总括/请求）？
2. "一是/二是"是否成组（≥3 条）？条首是否为概括短语？
3. 每条是否含具体数据或事实（数字+单位+时间）？
4. 单位是否全文统一（万千瓦时/万元/%）？
5. 政策文件是否用书名号+全称？
6. 问题表述是否注意分寸、归因客观？
7. 会议材料：标题（主、一、二级）是否对仗？政治站位表述是否到位？
8. 情况汇报：是否有"现将有关情况汇报如下"？请求事项是否明确到层级与目的？
9. 调研报告：是否有问题-措施对应关系？附表是否齐全编号连续？
10. 落款（单位全称/姓名）与日期是否完整？

## 七、文种差异速查

| 维度 | 调研报告 | 会议材料 | 情况汇报 |
|---|---|---|---|
| 篇幅 | 3—7 页 | 3—7 页 | 3—7 页 |
| 导语 | 缘起+方式+目的 | "主要任务是"段 | 依据+动作+"现将……" |
| 政治表述 | 少 | 必现（思想指导+全会精神） | 少 |
| 标题 | 平实式"关于××的调研报告" | 对仗愿景式+副标题 | 平实式"关于××情况的汇报" |
| 数据 | 极密+附表 | 密 | 密 |
| 附表 | 常有 | 少有 | 无 |
| 签名 | 单位或个人 | 报告人 | 单位 |
| 结尾 | 建议清单 | 号召表态 | 总括/请求 |

## 八、常见改错示例

| 问题写法 | 规范写法 |
|---|---|
| 今年我们搞了3个项目 | 今年以来，分公司累计落地项目3个 |
| 效果非常好，用户很满意 | 项目运行平稳，用户反馈良好 |
| 大概能省100万元左右 | 预计年节约成本约100万元 |
| 电量达到500万度 | 电量达到500万千瓦时 |
| 电压暂降治理项目 | 电压暂降治理项目（术语保留，不作口语化改写） |
| 装个储能设备 | 建设台区储能装置（30千瓦/xx千瓦时） |
