# 情况汇报材料风格指南

## 一、定位与适用

向本级领导或上级单位汇报某专项工作情况的短篇材料（3—7 页）。
核心任务：**讲清进展—说透问题—提实举措—争取支持**。
读者是决策者，要求结论前置、数据说话、请求明确。

## 二、结构骨架（四段式）

```
标题：关于××情况的汇报              ← 可回行；可加日期括注
（2026年9月11日）                    ← 可选，居中

[导语段]                             ← 依据+动作+目的，收尾"现将有关情况汇报如下。"

一、工作开展情况 / 前期工作进展
二、存在问题 / 当前面临的主要问题
三、下一步工作安排
四、需市公司协调事项 / 需要支持的事项（可选）

[落款] 单位全称
      2026年9月
```

变体：只报进展不报问题（纯通报型）；进展+安排（阶段小结型）；进展+问题+安排+请求（完整型，最常用）。

## 三、导语定式

**部署式**（上级有明确部署）：
> 按照公司关于推进台区储能示范项目的工作部署，分公司围绕摸清治理需求、筛选试点台区、研究商业模式、推动项目落地，扎实推进项目前期工作，先后完成赴××专题调研、全市××筛选核实及首批候选试点现场勘查等工作，现将有关情况汇报如下。

**贯彻式**（年度例行工作）：
> 今年以来，黄冈分公司认真贯彻落实省综关于市场化售电工作的各项部署要求，坚持稳住存量、拓展增量、优化服务，扎实推进市场化售电合同签订、履约执行、客户维护等各项工作，市场化售电业务总体保持平稳运行。现将有关情况汇报如下。

导语要素公式：`按照/今年以来 + 落实××部署 + 坚持××思路 + 推进××工作 + 现将有关情况汇报如下。`

## 四、条目三段式（本类文种核心）

**格式**：`一是+概括短语（判断句或四字动宾，以句号结尾）+ 具体内容`

### 1. 进展条目（"抓了什么—怎么抓—成效如何"）

> 一是专题调研进一步明确试点思路。9月17日，分公司赴武汉光谷综合能源服务有限公司开展台区储能专题调研，光谷综能总经理刘界江及项目核心团队参加座谈，重点了解其在试点建设、电力市场参与、商业模式设计及运维管理等方面的实践做法。调研中了解到，光谷综能在推进节奏和商业模式方面进行了积极探索：一方面，坚持试点先行……；另一方面，探索"电网购买服务+参与电力市场"的复合收益模式，……。结合调研情况看，当前台区储能政策性、专业性较强，市场机制尚不完善，宜坚持审慎推进，……再谋求规模化推广。

写法要点：
- 时间+主体+对象+方式，实词密；
- 用"一方面……另一方面……""其中……""同时……"组织长信息；
- 段末给出**判断性结论**（"结合调研情况看……宜……"），这是国网材料的价值点。

### 2. 问题条目（判断句开头）

> 一是商业模式尚未成熟。目前湖北台区储能暂无法按照现货电价机制参与相关交易，全省调频业务现阶段暂停，单纯依靠市场化收益尚难以覆盖项目投资。……特别是服务费与设备投资之间的边界如何把握、如何建立与实际治理效果挂钩的结算机制，对合同设计及法务、审计合规提出了较高要求。

常用问题定式：`××尚未成熟 / 尚未明确 / 尚未形成 / 存在一定制约 / 相对有限 / 有待进一步明确`

### 3. 措施条目（四字短语+动宾）

> 一是聚焦重点，加快首批试点落地。以××、××4个台区为重点，进一步核实××、××、××、××等建设条件，尽快锁定首批试点名单，同步做好备案、报装及招标前期准备。
> 二是深化模式研究，推动试点机制落地。……
> 三是强化协同推进，做好项目实施准备。……

措施条目动词库：聚焦、深化、强化、加快、做优、做实、拓展、健全、统筹、前置谋划。

## 五、问题表述的分寸

| 程度 | 表述 | 适用 |
|---|---|---|
| 轻微 | "有待进一步××""需持续关注" | 可控小问题 |
| 一般 | "尚未××""存在一定××""仍需进一步明确" | 机制类问题 |
| 较重 | "亟待××""亟需××""制约明显" | 影响落地的问题 |
| 不可写 | 人身指责、情绪化评价、"某某部门不作为" | 一律避免 |

原则：
- 归因指向**政策、机制、市场、客观条件**，不指向具体部门或个人；
- 问题后尽量接"目前已采取的措施"或"拟研究的方向"，体现担当；
- 涉及上级支持的问题，单独成段并写清"请求事项"。

## 六、请求支持段（第四部分）

> 一是明确试点建设统筹机制。建议市公司层面进一步明确台区储能试点牵头专业和相关部门职责边界，统筹配电、运检、营销、调度等专业协同推进，……为试点规范实施提供机制保障。
> 二是协调解决项目实施关键条件。建议市公司支持首批试点台区纳入供电质量提升等相关专项储备，在并网接入、台区运行数据提供、本地数据采集合规认定等方面给予指导和支持。

句式：`建议+层级/部门+动词（明确/协调/支持/统筹）+事项+，为××提供××保障/创造条件。`
跨级请求用"恳请"（"恳请省综推进协调能源局指标批复事宜"）；平级用"建议""需××支持"。

## 七、结尾定式

**总括式**：
> 总体来看，当前××业务既面临××等外部压力，也存在××等实际困难。下一步，××将坚持稳中求进，持续做好××工作，积极争取省综在××、××及××等方面给予支持，推动××业务稳规模、提质效、促转型，为公司××持续发展奠定基础。

**表态式**：
> 下一步，分公司将××，确保××取得实效。

## 八、落款与格式

- 落款单位写全称："国网湖北综合能源服务有限公司黄冈分公司"；日期到月（"2026年9月"）或到日。
- 有日期的汇报把"（2026年9月11日）"置于标题下方居中。
- 标题不加书名号；正文中引用的制度、方案加书名号。
- 数据要求：金额两位小数、比例两位小数、电量到万千瓦时、时间到日。

## 九、自检清单

- [ ] 导语是否用"现将有关情况汇报如下"收尾？
- [ ] 各段条目是否 ≥3 条且句式一致（一是+短语+句号+内容）？
- [ ] 进展条目是否含时间、主体、数据与结论？
- [ ] 问题表述是否注意分寸、归因客观？
- [ ] 请求事项是否写到"层级+事项+目的"？
- [ ] 结尾是否有总括/表态句？
- [ ] 落款单位全称与日期是否完整？
