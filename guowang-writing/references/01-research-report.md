# 调研报告风格指南

## 一、定位与适用

适用文种："关于××的调研报告""××专题调研报告""××工作开展情况的调研报告"。
读者是上级领导与平级部门；目的是**摸清情况、分析问题、提出建议**，兼具"情况说明"与"决策支撑"双重功能。
典型篇幅 3—7 页，常带附表（这是本类文种区别于情况汇报的最大特征）。

## 二、结构骨架（七段式）

```
标题：关于××的调研报告          ← 居中，可回行；可另起一行署名（单位+姓名）
〇 导语段                        ← 交代缘起、方式、目的，收尾"现将调研情况报告如下："
一、调研背景与调研概况            ← 行业/政策形势 + 本单位起点
二、××基本情况                    ← 分项说明对象现状（可含分条数据）
三、调研中发现的问题及原因分析    ← 本文核心，分条 + 归因维度
四、下一步工作思路及措施          ← 与问题一一对应
五、启发和建议（外部调研用）      ← 条目式建议（可选，与四并存）
附表：调研表1…、推荐表4…、工作计划表6…   ← 编号+完整表名
附件：××合同、××公告（可选）
```

小标题层级：`一、` → `（一）` → `1.` / `1）`（阶段编号可用 1）2）3））。

**变体结构：跟岗学习 / 先进经验类**（"专业工作报告"类，篇幅 1—3 页，无附表）
```
标题：关于提升××能力的调研报告 / 关于××工作情况的汇报
署名：姓名  单位（如"肖凯 国网冀北经研院"）
一、调研背景 / 学习背景      ← 派出安排 + 跟岗方式 + 时长 + 学习方向
二、先进做法 / 学习收获      ← "一是…二是…"连续排比，条目内不分段
三、工作建议                ← 对标本单位逐条转化，动宾短语开条
```
要点：收获条目用"一是××成效明显。""二是××作用突出。""三是××常态化。""四是××形式多样。"式对仗短语；建议条目用"一是加快人才队伍建设。""二是加强配电网运行通信支撑。"式动宾短语；收获与建议**条条对应**。此变体常见于外派学习、挂职锻炼、跨省调研后的成果材料。

## 三、导语三定式

**目的式**（内部自省型调研）：
> 为进一步提升工作质效，全面××，以适应新形势、新业务、新要求，特开展此次专题调研。

**学习式**（外部考察型调研）：
> 为了进一步开拓视野，学习国内先进的××建设、运营经验，创新工作思路，××团队赴××（单位）开展××业务调研学习。双方就××、××、××等方面内容进行了详细深入交流。现将相关情况汇报如下：

**受派式**（挂职/派出型调研）：
> 按照××统一安排，2023年2—7月，本人被派出到××公司挂职××，进行××的学习和锻炼。……通过资料查阅、座谈交流、实地考察等形式，全方位学习了解××的先进经验，形成此调研报告。

## 四、背景段写法

三层次递进：
1. **概念与意义**（排比句式）："××具有……特征，涉及……各环节。××有利于优化资源配置，……，是实现碳达峰、碳中和目标的重要路径，是推进……的关键抓手，是提升……的重要手段。"
2. **政策时间线**（年份+文件+要点）："2015年，国家政策层面首次提出……概念；……2016年《关于××的实施意见》首次提出了……，标志着……正式兴起。"
3. **市场数据**（权威来源+规模+趋势）："根据××数据，2023年××市场规模达到××亿美元，预计到2030年增长至××。"

## 五、问题段写法（核心）

**总起句**先给维度框架：
> 尽管××业务起步早、有示范，但在调研中发现，随着……，业务运营仍存在四大核心问题，需从"能力、资源、模式、生态"四个维度深挖根源。

**分条公式**：`一是+问题定性（含并列短评）+。+具体表现+实例佐证`

示例：
> 一是业务运营能力不足：专业人才短缺+技术支撑薄弱。项目运营"重建设、轻运维"，部分托管项目存在能效监测不实时、设备故障响应滞后等问题，如某医院项目曾因空调系统传感器故障未及时发现，导致单日能耗超预期。
> 二是资源整合能力有限：本地资源未盘活+外部合作不深入。……

要点：
- 定性短语可用"XX不足/有限/单一/薄弱"+冒号并列短语增强信息密度；
- 每条必须有**具体表现**，最好带一个"如××"实例；
- 数量用"四大核心问题""三个方面差距"点明，方便领导抓取。

## 六、措施段写法

**总起句**给思路提法（四字并列串）：
> 针对上述问题，结合国内外行业趋势与本地实际，下一步将以"强能力、整资源、创模式、树品牌"为核心思路，通过五大举措提升××水平。

**分条公式**：`一是+动作（双支撑/双联动等对仗提法）+，+目标（提升××能力）。+具体举措（可落到制度、手册、节点、指标）`

示例：
> 一是构建"人才+技术"双支撑，提升业务运营能力。打造复合型人才团队，培养一批"能源数字化""碳管理""能源交易"专业人才。建设统一智能管控平台，实现"数据互通、智能分析、一键调度"。
> 二是深化"本地+外部"双联动，提升资源整合能力。……

要点：措施与问题**一一对应**（问题四条→措施四/五条），且落到可执行物：制度文件、时间节点、责任主体、考核机制。

## 七、附表体系（本类文种特色）

三张典型表，编号连续（调研表1、2、3；推荐表4、5；工作计划表6、7）：

1. **调研表**——基本情况统计表 / 财务状况调研表。表头列名完整、单位在括号内，如"路灯数量（盏）""年用电量（万kWh)""财政资金状况"；末行"合计"。
2. **推荐表**——项目推荐表。必有"推荐理由及说明"列（从关系、资金、空间、属地支持等角度简述）。
3. **工作计划表**——阶段×时间节点矩阵：完成详细收资 / 完成可研编制 / 分公司初步内审 / 事业部内审 / 市场部组织评审 / 修编及定稿 / 上会决策 / 商务谈判、投标及合同签订 / 实施前准备 / 安装调试及验收 / 审计转运营；日期精确到日（如 2024.4.30）。

正文需以"具体见调研表1""推荐表4"等方式与附表呼应。

## 八、语言特征

- **数据密度**：每节至少一处数字；金额两位小数、比例两位小数、时间到日。
- **政策引用**：文件名全称+书名号，必要时带编号意义（"电改9号文配套文件《关于推进售电侧改革的实施意见》指出……"）。
- **对比分析**：外部调研常用"表格式对比"（面积/GDP/电量/架构/人数/营收/示范项目）。
- **对仗提法**：双字并列（"重建设、轻运维""懂能源不懂数字化"）、四字串（"强能力、整资源、创模式、树品牌"）。
- **来源标注**："根据××数据""结合调研情况看"。

## 九、范例片段（语感参照）

> 经初步摸排，××相关县市改造情况如下：高新采用节能效益分享模式已完成相关改造；……综上，推荐××县××路、××市××大道进一步开展××业务，具体详见推荐表4。
>
> 调研组认为，××业务政策性、专业性较强，市场机制尚不完善，宜坚持审慎推进，优先聚焦××一至两个核心目标，通过小规模试点验证技术、运营及商业模式，再谋求规模化推广。

## 十、自检清单

- [ ] 导语交代了调研缘起、方式（座谈/现场/资料/挂职）？
- [ ] 有政策时间线与市场数据支撑背景？
- [ ] 问题分条（≥3条）、每条带具体表现与实例？
- [ ] 措施与问题一一对应，且落到可执行物（制度/节点/指标）？
- [ ] 附表编号连续、表名完整、与正文呼应？
- [ ] 单位全文统一（万千瓦时/万元/%）？
- [ ] 有署名（单位或个人）与成文时间？
