# 会议材料风格指南

## 一、先判定子文种

| 子文种 | 判定信号 | 核心结构 |
|---|---|---|
| 年度工作报告 | "工作报告""职代会/工作会文件之一" | 成绩回顾 + 形势分析 + 任务部署（长篇，对仗一级标题） |
| 领导讲话 | "讲话""我讲三个方面意见" | 评价 + 形势 + 部署要求（三点意见式） |
| 专题报告 | "专题报告/方案报告" | 背景意义 + 分项方案 + 保障要求 |
| 表态发言 | "表态发言""我代表××作表态发言" | 聆听感受 + 过去成绩 + 新一年表态 |
| 总结讲话 | "总结讲话" | 总体评价 + 抓落实要求 |

汇编类材料（发言材料汇编、专题报告汇编）需先做目录，各篇独立起页、独立署名。

## 二、通用头部定式

```
（眉首/封面）
××公司××年工作会议文件之×          ← 单位名 + 年份 + 会议名称 + 文件序号
主标题：对仗愿景式（两段动词短语 / 四字+四字）
副标题：——在××公司××年工作会议上的报告（讲话）
（2026年2月4日）
报告人姓名                            ← 单独一行
```

**主标题实例**：
- "奋楫扬帆 勇毅笃行 在新征程上加快推进一流综合能源服务商建设"
- "开启卓越供电服务新征程 奋力推动市场营销工作高质量发展"

**专题报告标题**用平实式："关于卓越供电服务体系建设方案的报告""关于强化负荷管理、推进负荷管理中心规范化运营的报告"。

## 三、开篇定式

**报告类**：
> 同志们：
> 在"十四五"圆满收官、"十五五"开局起步之际，我们召开这次会议，主要任务是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十届四中全会和中央经济工作会议精神，落实省公司和国综集团"两会"部署，总结工作、分析形势、部署任务，……为××作出积极贡献。

**讲话类**：
> 下面，我讲三个方面的意见。

**专题报告类**：
> 各位领导，同志们：
> 根据会议安排，下面我作××方案的报告。……下面从四个方面进行简要报告。

**表态发言类**：
> 各位领导、同志们：
> 根据会议安排，我代表××公司作表态发言。
> 今天上午，我们认真聆听了×总讲话和××部工作部署，回首来时路……我们深感自豪、倍受鼓舞；踏上新征程，……我们深感责任重大、使命光荣。

## 四、主体骨架

### （一）年度工作报告

```
一、[工作总结]   ← 对仗标题，见下
（一）二级对仗标题
   三级要点句。+ 数据与做法
二、[形势分析]   ← "察形辨势，……"：外部形势 + 上级要求 + 自身短板
三、[任务部署]   ← 二级标题对仗，逐项部署
结尾：号召表态段
```

**一级标题对仗实例**：
> 一、砥砺深耕，硕果满枝，"十四五"奋斗历程谱写精彩华章

**二级标题对仗公式**：`××更加××，××持续××`
> （一）安全根基更加牢固，风险防线持续筑牢
> （二）轻资产运营成效凸显，新兴领域协同发力
> （三）核心业务量质齐升，发展动能持续增强

**三级要点写法**：概括短语独立成句 + 数据堆叠
> 安全责任体系不断健全。加快融入省公司"同质化"管理体系，全面梳理分（子）公司安全管理责任界面……组织修订完善安全管理文件23项。
> 市场化交易支撑稳健发展。作为当前最重要的营收来源之一，公司团队直面市场竞争，全年累计签约电量136.05亿千瓦时，创收4125.64万元，有效稳固经营的基本盘。

### （二）讲话（三点意见式）

```
一、拼搏奋斗，攻坚克难，××年××工作成效显著
   一是在××上展现了新作为。……（分条列成绩）
二、认清形势，把握大势，……（机遇挑战判断）
三、聚焦重点，……（部署要求）
结尾："最后，我再强调几点。" / 号召段
```

成绩分条定式："一是在扛牢××首要责任上展现了新作为""二是在推动××上展现了新作为"。

### （三）表态发言

```
1. 聆听感受（自豪/责任重大 + 对会议部署的理解）
2. 过去一年成绩："一是打造××'组合拳'""二是打造××'新模式'""三是打造××'策源地'"（每条成绩后跟数据）
3. 新一年表态："一是聚焦工作大局，在'保供转型'中再登高、走在前"（公式：聚焦××，在"××"中再××、走××）
4. 结尾："请总部放心，××公司一定坚决落实好××部署，勇当排头、勇毅前行，奋力谱写××新篇章，为全面建设具有中国特色国际领先的能源互联网企业作出新的贡献！"
```

### （四）专题报告

```
各位领导，同志们：根据会议安排，下面我作××的报告。
一、××的时代背景和总体要求   ← （一）背景（二）总体要求（含目标分阶段："到2025年……；到2030年……"）
二、推进××建设             ← 分条：1.推进…… 2.推进……
三、保障措施
结尾："以上报告，请予审议。"
```

## 五、成绩与数据表述

- 经营口径："全年实现营业收入3.29亿元、利润总额2564.60万元，核心业务占比达95.55%，整体经营保持稳中向好态势。"
- 增长率："利润同比增长48.73%""所有者权益增幅近120%""交易收益增长23.98倍"。
- 荣誉试点："成功注册并运营全省首个××""荣获××奖特等奖""入选《××案例》""获评'专精特新'中小企业"。
- 突破性表述："实现规模化开局""实现运营突破""培育新增长点""取得实质性验证""成功路径探索"。
- 五年/年度回顾常用"这五年，是……向……实现能级跃升的五年"排比段。

## 六、语言与体例

- **政治站位必现**：以习近平新时代中国特色社会主义思想为指导；全面贯彻党的二十届×中全会精神；落实"第一议题"制度；"三重一大"；"两个确立"等提法保留引号。
- **四字对仗**：砥砺深耕、硕果满枝、量质齐升、风清气正、凝心铸魂、勇毅笃行、靶向破题、稳中向好。
- **动词统领二级标题**：健全、深化、提升、突破、彰显、增强、迭代、穿透、夯实、筑牢。
- 段落之间用"回首××征程""一年来""这五年"承接；部署段用"一要……二要……三要……"或"一是……二是……"。
- 结尾号召段必含"为××作出新的贡献/注入强劲动能"。
- 人名职务首次出现写全（"光谷综能总经理刘界江"），后文从简。

## 七、范例片段（语感参照）

> 回首"十四五"壮阔征程，面对风高浪急的市场环境与滚石上山的转型压力，公司始终保持战略定力，紧扣"建设一流综合能源服务商"宏大愿景，坚定不移走市场化道路，深入践行"轻资产、平台型、防风险、高质量"发展方针。

> 新号角激荡人心，新征程风鹏正举。请总部放心，××公司一定坚决落实好国家电网公司和××专业工作部署，勇当排头、勇毅前行，奋力谱写××高质量发展新篇章。

## 八、自检清单

- [ ] 子文种判定正确（报告/讲话/专题/表态/总结）？
- [ ] 头部五要素齐全：单位+年份会议名、主标题、副标题、日期、报告人？
- [ ] 主标题对仗、一级二级标题对仗？
- [ ] 开篇含"主要任务是"段与政治站位表述？
- [ ] 成绩条目有数据（金额/电量/比例/件数）？
- [ ] 结尾有号召/表态收束句？
- [ ] 人名、单位、职务完整准确？
