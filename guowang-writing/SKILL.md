# 国网公文写作

## 概述

按国家电网体系公文风格产出三类材料。该风格的核心是：**依据开篇、数据密集、对仗标题分节、"一是/二是"条列推进、结尾表态收束**。三类文种在结构骨架、语言规范上高度同源，差异集中在篇幅、政治表述密度、附表体系与结尾定式。

适用场景：调研报告、会议材料（年度工作报告 / 领导讲话 / 专题报告 / 表态发言 / 总结讲话）、情况汇报材料。

## 第一步：识别文种

| 用户说法 | 文种 | 必读参考 |
|---|---|---|
| 调研报告、调研汇报、考察报告、学习调研、专题调研 | 调研报告 | `references/01-research-report.md` |
| 工作报告、领导讲话、表态发言、总结讲话、职代会材料、工作会材料、发言汇编 | 会议材料 | `references/02-meeting-materials.md` |
| 情况汇报、进展汇报、汇报材料、"关于××情况的汇报" | 情况汇报材料 | `references/03-report-briefing.md` |

- 识别后**必须先读取对应参考文件，再动笔**——骨架、句式、用词均在其中。
- 文种跨类（如"情况汇报+请示支持"）时，读主文种参考，搭配 `references/04-language-norms.md`。
- 无论哪类，成稿前都需过一遍 `references/04-language-norms.md` 的自检清单。

## 第二步：采集要素

动笔前按下表核对信息。**用户未提供的，按语境合理推定并在稿末以简短说明标注假设，不要为细节反复追问**。

| 文种 | 必要要素 |
|---|---|
| 通用 | 单位全称、成文时间（年月）、署名方式（单位/个人） |
| 调研报告 | 调研对象与缘起、调研方式（座谈/现场/资料）、数据（数量/金额/比例）、问题条数与维度、是否需附表（调研表/推荐表/工作计划表） |
| 会议材料 | 会议名称（第×届×次会议 / ××年工作会议）、子文种、报告人姓名职务、年度主题、需引用的上级会议与文件 |
| 情况汇报 | 汇报对象（省公司/市公司/上级部门）、起因（"按照××部署"）、进展与数据、问题条数、是否需"需协调支持事项"段 |

默认主体：如素材为黄冈口吻且用户未说明，署名用"国网湖北综合能源服务有限公司黄冈分公司"；其他单位以用户为准。

## 第三步：按骨架成稿

1. 从对应参考文件复制结构骨架，逐节填充；
2. 保持参考文件中的**句式定式**（导语、条目、结尾）与**对仗提法**（四字短语、双字并列）；
3. 三类文种关键差异速查（详见 04 号参考）：

| 维度 | 调研报告 | 会议材料 | 情况汇报 |
|---|---|---|---|
| 篇幅 | 3—7 页 | 3—7 页 | 3—7 页 |
| 政治表述 | 少 | 必现 | 少 |
| 附表 | 常有 | 少有 | 无 |
| 结尾 | 建议清单 | 号召表态 | 总括/请求 |

## 第四步：风格自检（必做）

运行 `scripts/style_check.py <稿件路径>` 做机器检查（半角标点、单位规范、条目结构等），再对照 `references/04-language-norms.md` 第六节清单人工复核。发现问题直接修改，不把问题留给用户。

## 第五步：交付

- 默认输出 Markdown；**需 Word 正式件时，转交 `workbuddy-office-routing` → `workbuddy-docx`**（公文排版另有 `gongwen-paiban` 技能可用）。
- 文件命名遵循"关于××的××（版本）"习惯，如`关于黄冈台区储能开展情况的汇报V6`。
- 定稿后在回复中给出：结构一览、关键数据来源假设、需用户确认的待补信息。

## 铁律

1. **数据必须具体**：金额到万元、比例到两位小数、时间到日、电量到万千瓦时。
2. **"一是/二是/三是"必须成组**（≥3条），条首为概括短语（判断句或四字动宾），再接具体内容。
3. **会议材料标题必须对仗**：主标题用四字+四字或动宾短语串接，一级/二级标题用对仗式。
4. **开篇交代依据与目的**：以"按照/为/围绕……，现将有关情况汇报如下"类定式收尾导语。
5. **问题表述讲分寸**：用"尚未成熟""存在一定制约""仍需进一步明确"，归因指向客观条件。
6. **向上请求写"建议/恳请"**："建议市公司层面……""恳请省综……"。
7. 不用口语与网络语；正式件不用第一人称单数"我"（署名式"本人"除外）。
8. 政策文件用书名号+全称，如《湖北省碳普惠体系建设实施方案（2024—2027年）》。
9. **结尾必须有收束句**（表态 / 总括 / 请求）。
10. 单位全文统一：万千瓦时、千瓦（kW）、万元、%——不写"度"。
